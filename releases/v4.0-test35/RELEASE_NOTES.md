# 医键住院管理 4.0-test35

## 本版修复

- 修复“大模型配置”中用户选择 MiMo V2.6 后，重新进入页面又显示 MiMo V2.5 的问题。
- 修复提供方下拉框首次布局时的异步回调：相同的提供方不再触发“切换到默认模型”。
- 修复模型列表加载完成后的程序化选项回调：不再把列表第一条模型覆盖到当前模型。
- 已保存模型在模型列表中时优先恢复已保存值；只有保存值不在列表中时才使用提供方默认值。
- 测试连接和保存直接读取下拉框当前选中的精确模型 ID。
- 保存改为同步写入本地配置，写入失败时不会显示“已保存”。
- 保存后会立即重新读取提供方和模型 ID，只有实际保存值与界面选择完全一致时才退出页面。
- DeepSeek 默认模型原本就是第一项，因此过去没有暴露问题；本次修复同样覆盖 DeepSeek。
